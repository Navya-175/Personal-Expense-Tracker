# Personal Expense Tracker

A lightweight browser-based expense tracker built with HTML, CSS and vanilla JavaScript.

## Features
- Add expenses with a description, amount, category and date
- View and delete transactions
- Filter transactions by category
- Calculate total expenses and current-month expenses
- Persist data in browser `localStorage`
- Responsive layout for desktop and mobile screens

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add an expense to get started.

No build tools or dependencies are required.

## Tech stack
- HTML5
- CSS3
- JavaScript (ES6+)
- Browser localStorage

## Data and limitations
This is a frontend-only demo. Expense data stays in the browser where it was entered. It does not include user accounts, cloud sync, a backend API, MySQL, Flutter or Dart.
